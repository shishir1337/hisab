# Hisab M5 — Web App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The web app is where you review the month:
- A two-column dashboard.
- A dense Activity table with bulk actions.
- A fast keyboard quick-log (press `N`) and a ⌘K command bar.
- A monthly report with CSV and PDF export, plus "export all data".

**Architecture:**
- **Pure logic in `packages/core`:** report aggregation and CSV building.
- **Quick-log form state moves to `packages/db`** (it depends on db types) so web and mobile share it.
- **Web UI:** client components on the in-browser PowerSync database, with shadcn-style primitives on Radix Dialog, `cmdk` and `sonner`.

**Spec:** §7.2 (web navigation), §7.3 (Monthly report), §7.4 (Web specifics), §8 (Export all data)

## Global Constraints
- Same tokens, money formatting (ISO codes, South Asian grouping) and queries as mobile; no new balance math on web.
- Keyboard first: `N` opens quick-log anywhere (except inside inputs), ⌘K/Ctrl+K opens the command bar, Enter saves, Esc closes.
- Exports never leave the browser. Files are generated client-side from local SQLite.

## Review Focus
1. **Spreadsheet-safe CSV:** commas, quotes, newlines and leading `=+-@` characters (formula injection) in notes are escaped. Tested in Task 1.
2. **Report percentages when income is zero:** savings rate shows "—", not NaN or Infinity. Tested in Task 1.
3. **Vs-last-month comparison** when last month had no data. Tested in Task 1.
4. **The `N` shortcut** does not fire while typing in an input or textarea, or while a dialog is open. UI guard.
5. **Bulk recategorize** only applies to expense/income rows matching the chosen category's kind. Tested in Task 2 (db `bulkRecategorize`).

### Task 1: core — report and CSV
- `monthlyReport(rows, prevRows)` returns:
  - income, expense, emi, lent out, collected in, net and savings rate;
  - spending by category and income by source;
  - deltas versus last month.
- `toCsv(columns, rows)`, using RFC 4180 quoting and formula-injection guarding.

### Task 2: db — shared quick-log form and bulk operations
- Move `apps/mobile/src/features/quick-log/form.ts` (with its tests) to `packages/db/src/quick-log-form.ts`.
- Add `bulkSoftDelete(ex, ids)` and `bulkRecategorize(ex, ids, categoryId)`, which only touches rows of the same kind.
- Add `Q.reportRows(start, end)`.

### Task 3: web — primitives, profile and shortcuts
- **Primitives:** Dialog (Radix), Select, Toast (sonner), Command (cmdk).
- **Data hooks:** `useProfile` and `useToday`.
- **Keyboard:** global `N` / ⌘K handling.
- **Quick-log dialog:** add and edit, built on the shared form reducer.
- **Command bar.**

### Task 4: web — Dashboard and Activity
- **Home:** hero + Due soon (left); month In/Out, top categories bar list and budgets (right).
- **Activity table:**
  - Month switcher, search, and type/account/category filters.
  - Sortable columns and checkbox multi-select.
  - Bulk delete and recategorize, both with undo.
  - Clicking a row edits it.

### Task 5: web — Plan, People, Reports, Settings
- **Plan and People:** read views with key actions (mark EMI paid, record or skip due items, Got paid).
- **Reports:** the monthly report page, with CSV export and a print stylesheet for PDF.
- **Settings:** accounts (add, edit, archive), theme, "Export all data" (ZIP of CSVs via `fflate`), and sign out.

### Task 6: verification
`turbo typecheck test`, the web build, a Playwright smoke test (temp user, deleted afterwards) covering quick-log, the Activity table and report export, and the ledger.
